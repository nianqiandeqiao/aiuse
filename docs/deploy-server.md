# 自购云服务器部署指南（最稳的方案）

## 一、先买什么

| 项目 | 建议 | 说明 |
| --- | --- | --- |
| 产品 | 腾讯云 / 阿里云的**轻量应用服务器** | 比云服务器 CVM/ECS 便宜、更好上手，控制台简单 |
| 配置 | **2 核 2G**，SSD 40G 以上，带宽 3M 起 | 根目录里应用 + MySQL 同机运行，2G 够用；预算够就 2核4G 更宽松 |
| 价格 | 约 24~40 元/月；学生机约 10 元/月 | 学生认证后在「校园计划」里买，最划算 |
| 系统镜像 | **Ubuntu 22.04 LTS** | 不要选 Windows（浪费内存）和 CentOS（已停止维护） |
| 地域 | 选离你近的：郑州/武汉/上海/北京/广州 | 越近访问越快 |
| 备案 | **只用 IP 访问不用备案**；绑域名才需要 | 备案约 1~2 周，演示阶段先用 IP |

## 二、买完怎么连上去

在云厂商控制台可以点「远程登录 / 网页终端」，也可以在自己电脑上用 SSH：

```powershell
ssh root@你的服务器公网IP
```

（Windows 10/11 自带 ssh 命令；密码在控制台可以重置。）

## 三、两条命令部署

连上服务器后，依次执行（把仓库地址换成你自己的）：

```bash
# 1. 装 git 并拉取代码
apt-get update -y && apt-get install -y git
git clone https://gitee.com/nianqingdeqiaojiangjun/aiuse.git ~/aiuse

# 2. 一键部署（自动装 Docker、起 MySQL 和应用）
cd ~/aiuse && bash deploy/install-server.sh
```

脚本会依次问你四个问题：

1. **MySQL root 密码** —— 直接回车用默认 `medreminder`，**正式用请改成复杂密码**；
2. **百度 OCR API Key / Secret Key** —— 不填也能跑，但拍照识药不可用；
3. **是否允许自助注册账号** —— 默认 `true`；不想让陌生人注册就填 `false`（之后账号要让管理员在数据库里加）。

脚本会自动完成：装 Docker → 生成 `.env`（权限 600，只有 root 能读，密钥不进仓库）→ 构建镜像并启动应用与 MySQL → 放行本机防火墙 → 自检并打印访问地址。第一次构建大约 **5~10 分钟**。

## 四、别忘了放行安全组（最容易踩的坑）

脚本只能放行服务器**本机**的防火墙，云厂商还有一层**安全组 / 防火墙**，必须手动放行：

腾讯云：轻量应用服务器 → 防火墙 → 添加规则 → TCP 端口 **8081** 放行（来源 `0.0.0.0/0`）。
阿里云：轻量应用服务器 → 防火墙 → 添加规则 → 端口 **8081**。

放行后浏览器打开 `http://你的公网IP:8081/`，注册一个账号就能用。

## 五、日常运维命令

在项目目录 `~/aiuse` 下执行：

```bash
docker compose logs -f app      # 看应用日志
docker compose ps               # 看容器状态
docker compose restart app      # 重启应用
git pull && docker compose up -d --build   # 更新代码后重新部署
docker compose down             # 停止全部（数据库数据仍保留在数据卷里）
```

**数据库备份**（建议每周一次，把数据导出到本机保存）：

```bash
docker exec med-mysql mysqldump -uroot -p"你的密码" med_reminder > ~/backup-$(date +%F).sql
```

## 六、关于语音功能（重要）

用 **IP + http** 访问时，浏览器会禁止网页调用麦克风（这是浏览器的安全策略，跟我们的程序无关），所以「语音提问」在 IP 访问下用不了；**其他功能全部正常**（到点提醒弹窗、语音播报、拍照识药、冲突检查、报告、文字提问都能用）。

想要手机上也能语音提问，需要 **https**，两条路：

1. 买个域名（几十元/年）→ 解析到服务器 IP → 在阿里云/腾讯云申请免费 SSL 证书 → 备案（国内服务器必须）→ 用 Nginx 配 https；
2. 或者用 Cloudflare 免费套餐代理你的域名（也需要域名）。

答辩演示时如果不想折腾域名，直接在电脑上用 `http://localhost:8081` 演示语音（localhost 属于安全上下文），或者用文字提问，效果一样完整。

## 七、安全提醒

1. 数据库密码别用默认的 `medreminder`，脚本第一问就要改；
2. 服务器 root 密码设复杂些，SSH 端口可以考虑改掉；
3. 只开放必要端口：8081（应用）。**MySQL 的 3306 不要对公网开放**（我们的 compose 里没有暴露 3306，这是对的）；
4. 演示结束不用了，记得在控制台**关机或到期退订**，避免持续计费；
5. 老人健康数据属于敏感个人信息，公开演示请**只用虚构数据**。
