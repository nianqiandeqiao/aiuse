## 2. 测试策略

采用三层测试，兼顾"白盒验证代码正确性"与"黑盒验证接口可用性"：

| 层次 | 工具 | 位置 | 特点 |
| --- | --- | --- | --- |
| 持久层测试 | JUnit 5 + Spring Boot Test | `ElderMapperTest` | 验证 SQL、字段映射、主键回填、逻辑删除 |
| 业务层测试 | JUnit 5 + Spring Boot Test | `CheckinServiceTest`、`InteractionServiceTest`、`DrugDictionaryTest` | 验证业务规则、冲突判定、药名归一 |
| 接口层测试 | JUnit 5 + MockMvc | `ElderApiTest` | 验证统一响应体、参数校验、404 语义 |
| 端到端接口测试 | PowerShell 脚本 | `scripts/smoke-test.ps1` | 打真实 HTTP 接口，含真实百度 OCR 调用 |

所有 JUnit 测试类均加了 `@Transactional`，测试数据在方法结束时自动回滚，**不污染开发数据库**。

## 5. 缺陷记录与修复

| 编号 | 问题 | 原因 | 处理 |
| --- | --- | --- | --- |
| BUG-01 | 打包失败 `Unable to rename ... .jar` | Windows 下运行中的后端进程锁定了 jar 文件 | 先停止服务再打包，并在脚本中固化"停服务→构建→启动"顺序 |
| BUG-02 | 构建中断后 `repackage` 报 `Index 0 out of bounds` | 中断产生 22 字节的损坏 jar，增量打包失败 | 执行 `mvn clean package` 全量重建 |
| BUG-03 | 启动报 `No qualifying bean of type RestClient.Builder` | Spring Boot 4 将 `RestClient` 自动配置拆到独立模块，项目未引入 | 改为 `RestClient.create()`，不额外引入依赖 |
| BUG-04 | 冒烟脚本解析报错、中文乱码 | Windows PowerShell 5.1 按 ANSI 读取无 BOM 的 UTF-8 脚本 | 脚本内容全部改为纯 ASCII，中文数据用 Unicode 码点构造 |
| BUG-05 | 老人删除后残留"孤儿"用药计划 | 删除老人时未处理其计划 | 删除老人时级联停用其全部用药计划，并清理历史遗留数据 |
